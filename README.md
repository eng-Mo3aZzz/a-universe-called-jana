# A Universe Called Jana

Act as a world-class creative director, UI/UX designer, 3D web experience designer, and senior frontend developer.

Create an extraordinary, cinematic, interactive birthday website titled:

"A Universe Called Jana"

This website is a personalized birthday gift for a girl named Jana (جنى), designed to feel like a magical journey through a beautiful universe.

IMPORTANT:
Do not create a generic birthday website or a simple landing page.
Build a complete, immersive, multi-stage interactive experience with premium visuals, smooth animations, emotional storytelling, playful interactions, and excellent mobile usability.

The website must be designed MOBILE-FIRST because the primary user will access it through a smartphone browser.
